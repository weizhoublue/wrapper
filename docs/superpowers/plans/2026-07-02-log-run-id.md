# Log Run ID Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 在每条 wrapper debug/info/error 日志中插入一个 6 位 run ID，使多并发 CI 场景下可通过 ID 过滤同一次调用的全部日志。

**Architecture:** 在 `src/log.js` 模块加载时，计算一次性 6 位 run ID（秒末3位+毫秒3位），写入模块级常量。`write()` 函数将 ID 插入 `[wrapper]` 与日志级别之间。无新 API，无参数变更。

**Tech Stack:** Node.js (node:test, assert)

## Global Constraints

- 仅修改 `src/log.js` 和 `test/log.test.js`，不改其他文件
- git commit 必须使用 `git commit -s -S -m`
- ID 格式：6 位纯数字，`String(s % 1000).padStart(3,'0') + String(ms).padStart(3,'0')`

---

- [ ] **Step 1: 写失败测试（新格式断言）**

在 `test/log.test.js` 中，将所有 `assert.match` 正则从 `[wrapper][level]` 改为 `[wrapper][NNNNNN][level]`（`\d{6}` 匹配 run ID）：

```js
// 修改 line 46: info writes when debug enabled
assert.match(output, /\[wrapper\]\[\d{6}\]\[info\]\[\d{4}-\d{2}-\d{2} \d{2}:\d{2}:\d{2}\.\d{3}\] hello world\n/);

// 修改 line 52: error writes when debug enabled
assert.match(output, /\[wrapper\]\[\d{6}\]\[error\].* fail 500\n/);

// 修改 line 58: debug writes when enabled
assert.match(output, /\[wrapper\]\[\d{6}\]\[debug\]\[\d{4}-\d{2}-\d{2} \d{2}:\d{2}:\d{2}\.\d{3}\] secret xyz\n/);

// 修改 line 71: prefix includes agent and session when context set
assert.match(output, /\[wrapper\]\[\d{6}\]\[debug\]\[\d{4}-\d{2}-\d{2} \d{2}:\d{2}:\d{2}\.\d{3}\]\[codex\]\[1\/3\] spawn\n/);

// 修改 line 78: prefix uses dash session when attempt not set
assert.match(output, /\[wrapper\]\[\d{6}\]\[info\].*\[codex\]\[-\] trying\n/);

// 修改 line 85: prefix omits agent bracket when no context
assert.match(output, /\[wrapper\]\[\d{6}\]\[info\]\[\d{4}-\d{2}-\d{2} \d{2}:\d{2}:\d{2}\.\d{3}\] wrapper starting\n/);

// 修改 line 93: error level gets context prefix
assert.match(output, /\[wrapper\]\[\d{6}\]\[error\].*\[codex\]\[2\/3\] non-zero exit code 1\n/);
```

- [ ] **Step 3: 实现 RUN_ID（修改 src/log.js）**

在 `src/log.js` 第 4 行之前（`let debugEnabled` 之前）插入：

```js
const _start = new Date();
const RUN_ID = String(_start.getSeconds()).padStart(3, "0").slice(-3) + String(_start.getMilliseconds()).padStart(3, "0");
```

> 注：`String(seconds).padStart(3,'0').slice(-3)` 等价于 `String(seconds % 1000).padStart(3,'0')`，但更直接。

修改 `write()` 函数（当前 line 23）：

```js
// 之前
let line = `[wrapper][${level}][${timestamp()}]`;

// 之后
let line = `[wrapper][${RUN_ID}][${level}][${timestamp()}]`;
```
